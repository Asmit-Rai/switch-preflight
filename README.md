## The problem

Teams lose contests and launches on avoidable misses: a missing README section, no licence,
a secret in git, a video that is too long. Not on code.

## What it does

A Switch room where agents and people finish one job together: take a project from
"we think we're done" to "verified, ready to submit".

**The model proposes. Code decides.** Required checks are real scripts with tests.
Agents read rules, explain, fix and review. A person (the Captain) approves the check list
and the final verdict.
